## 功能缺口

### 1. CMS API 接入 (website 发布)

当前 website 发布只生成 manual pack，需要接入 rongwang 的 CMS API。

**需要的 API**:
- `POST /api/cms/articles` — 创建文章草稿
- `PATCH /api/cms/articles/:id` — 更新文章
- `GET /api/cms/articles/:slug` — 读取现有文章

**接口负责人**: 需要确认 CMS API 是否已实现。

### 2. Wechatsync Cookie 管理

当前 Wechatsync 的 Cookie 来自 Chrome Profile，存在以下问题:
- Cookie 有效期短（通常 1-2 周）
- 需要手动更新
- 没有过期提醒

**建议**: 增加 Cookie 过期检测 + 飞书通知。

### 3. Vercel Cron 定时触发

Pipeline v1 目前需要手动触发。
需要配置 Vercel Cron 实现自动化。

**需要的 Cron Job**:
```json
{
  "path": "/api/cron/marketing-pipeline",
  "schedule": "0 9 * * *"  // 每天 9:00 UTC
}
```

### 4. Agent-Reach 集成

Agent-Reach 提供的研究能力可以增强内容质量：
- 真实竞品内容分析
- 用户评价研究
- 行业趋势洞察

**集成方式**: 只读研究，不修改 Pipeline 流程。

### 5. 小红书 API

小红书开放平台 API 需要申请：
- 企业号认证
- 内容 API 权限
- 自动发布权限

**当前状态**: 不可用，仅手动发布。

## 运营 SOP

### 每日营销 Pipeline 检查清单

```bash
# 1. 检查 Evidence 目录
ls -la data/marketing-runs/

# 2. 检查 Manual Packs
ls -la .ai/marketing-manual-packs/

# 3. 检查 Wechatsync 状态
docker ps | grep wechatsync

# 4. 检查 Feature Flags
FEATURE_MARKETING_PIPELINE=true pnpm tsx scripts/marketing/pipeline-runner.ts \
  --job .ai/marketing-jobs/sample-rongwang-sleep-001.json --mode dry-run
```

### 内容发布流程

1. **选题** → 添加 Job JSON 到 `.ai/marketing-jobs/`
2. **生成** → 运行 Pipeline 生成内容
3. **检查** → Review Evidence + Manual Pack
4. **发布** → 人工发布到各平台
5. **记录** → 更新运营表格
