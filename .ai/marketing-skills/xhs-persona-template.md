# 小红书 Persona 模板

**版本**: v1.0 | **用途**: 小红书内容选题和风格指导 | **注意**: 本文件为原创模板，不复制自任何外部技能库

---

## 平台概述

- **月活用户**: 2亿+
- **主要用户**: 18-35岁女性为主
- **内容形式**: 图文笔记（竖版图片+短正文）、短视频
- **核心机制**: 标签算法、互动权重（点赞/收藏/评论/关注）

---

## 平台红线（绝对禁止）

1. **医疗夸大** — 不可出现：治愈、根治、治疗、诊断、处方
2. **绝对化承诺** — 不可出现：100%有效、保证、一定、永久
3. **虚假宣传** — 不可出现：伪造用户体验、虚假数据
4. **导流站外** — 不可直接引导至微信/其他平台
5. **AI 生成内容标识** — 不得标注"AI生成"
6. **政治敏感** — 不可涉及政治话题
7. **侵权内容** — 不得使用未授权图片/音乐

## 小红书内容 SOP

### 标题规范
- 长度: 12-20 字最佳
- 结构: 痛点 + 解决方案 + 情绪词
- 公式: `救命！` / `姐妹们` / `真的哭死` + 具体问题 + 效果词
- Emoji: 开头使用 🉑❌⚠️💡🔥 等增强注意力

### 封面图规范
- 比例: 3:4 (1080×1440px)
- 风格: 真实生活场景 > 精致摆拍
- 文字: 大字标题 + 副标题
- 色调: 明亮、高对比、有质感

### 正文规范
- 字数: 300-800 字（碎片化阅读）
- 段落: 短段落，3-5 行一段
- 结构: 痛点引入 → 个人经历 → 干货建议 → CTA
- Emoji: 适度使用（每段 1-2 个）
- 标签: 3-5 个垂直标签 + 1-2 个热度标签

## Persona 模板

### 睡眠健康 Persona

**目标人群**: 25-40岁职场女性，有睡眠困扰
**内容调性**: 亲切、共鸣、实用、有温度

```
【痛点引入】
最近总是睡不好？翻来覆去到凌晨...

【个人经历】
我之前也是...后来发现...

【干货分享】
✅ 方法1: ...
✅ 方法2: ...
✅ 方法3: ...

【产品/方案提及】
(自然引入，不硬广)
最近在用荣旺的...感觉...

【互动引导】
你们有什么助眠好方法？评论区告诉我！
```

### 护肝/解酒 Persona

**目标人群**: 30-50岁商务男性，应酬多

```
【场景痛点】
每次应酬完第二天整个人都垮了...

【知识科普】
酒精代谢的原理是...

【产品自然植入】
最近发现一款...成分很扎实

【互动】
你们喝酒后都怎么缓解？
```
