## 二、建议的更新频率

### 2.1 页面类型更新节奏

| 页面类型 | 更新频率 | 每次更新内容 | 执行动作 |
|---------|---------|-------------|---------|
| **首页** | **每周1次小调/月1次大调** | 精选文章/方案/用户评价轮换 | 更新推荐模块、案例展示、促销Banner |
| **方案页**（/solutions/[slug]） | **每2周1次** | 健康小贴士/FAQ/最新研究摘要 | 添加新段落、更新研究数据、补充方案适用场景 |
| **文章页**（/articles/[slug]） | **每月2-4篇** | 按内容日历发布新文章 | 创建新文章、补充现有系列 |
| **博客页**（/blog） | **每周1篇** | SEO长文/热点借势/用户故事 | 发布深度内容，建立主题集群 |

### 2.2 内容更新优先级矩阵

```
高优先级（每周执行）：
├── 首页轮换推荐（3篇文章/方案）
├── 方案页补充最新研究数据（2个方案）
└── 社交媒体内容回收发布

中优先级（每两周执行）：
├── 文章页新增内容段落
├── 旧文章SEO元素更新
└── 内容话题转化为文章

低优先级（每月执行）：
├── 全站内容健康检查
├── 失效链接/过时数据修复
└── 新主题内容规划
```

### 4.2 平台适配策略

**小红书（种草向，500-800字）：**
```
格式要求：
- 标题：数字+痛点+感叹号（"3个信号说明你缺辅酶Q10！"）
- 正文：emoji+分段+行动号召
- 图片：高颜值产品图+信息图

内容改编原则：
- 从SEO文章提炼核心观点
- 增加第一人称使用体验
- 添加具体产品推荐（荣旺方案链接）
- 结尾引导评估/咨询

示例改编：
SEO文："辅酶Q10适合什么人？30岁+熬夜党的心脏急救包"
小红书："协和营养师说：30岁后每天补充这个，心脏悄悄变好！"
```

**抖音（科普向，60秒）：**
```
结构要求：
- 0-3秒：强钩子（"你知道你的心脏在求救吗？"）
- 3-20秒：核心知识点（1个观点+数据支撑）
- 20-45秒：解决方案（GABA/辅酶Q10等成分）
- 45-60秒：行动号召（"评论区扣1，帮你分析"）

内容改编原则：
- 从SEO文章提炼1个爆点
- 语言口语化，避免专业术语
- 添加字幕和BGM
- 每周固定更新1-2条

示例改编：
SEO文："心脏最怕你996：辅酶Q10到底是不是智商税？"
抖音脚本："996心脏在求救！辅酶Q10是智商税还是真有用？医生说出了真相..."
```

**公众号（深度向，1500-2000字）：**
```
格式要求：
- 标题：引发好奇或共鸣
- 开头：场景化痛点描述
- 正文：3-4个小标题，逻辑递进
- 结尾：总结+产品/方案推荐

内容改编原则：
- 将多篇SEO文章整合为深度专题
- 增加案例故事和数据引用
- 保持专业但可读性强的风格

示例改编：
专题："辅酶Q10完整指南：从选品到使用的2000字攻略"
（整合：选购指南+真实测评+适用人群+使用指南）
```

**邮件营销（个性化，促转化）：**
```
触发场景：
- 新订阅用户：欢迎序列（健康评估引导）
- 看完辅酶Q10文章：辅酶Q10适用自测+产品推荐
- 看完睡眠文章：睡眠方案个性化推荐
- 复购提醒：基于购买历史的交叉推荐

内容策略：
- 每个内容主题对应1封教育邮件
- 教育邮件末尾引导完成评估
- 评估完成后发送个性化方案邮件
```

## 五、SEO与GEO双重优化建议

### 5.1 传统SEO优化

**关键词布局：**
```markdown
核心关键词（每篇文章）：
- 辅酶Q10：搜索量高，竞争激烈 → 专题集群
- 水飞蓟宾：搜索量中，转化意图强 → 护肝专题
- 甘氨酸镁：搜索量低，意图精准 → 睡眠专题
- 维生素D3：搜索量高，竞品多 → 差异化角度

长尾关键词（FAQ/小标题）：
- 辅酶Q10能长期吃吗
- 还原型和氧化型区别
- 适合什么人群
```

**技术SEO：**
```markdown
- 确保文章页加载速度 < 2s
- 添加内部链接（文章→方案页→产品页）
- 图片添加alt标签
- Canonical标签防止重复内容
```

### 5.2 GEO（AI搜索）优化

**结构化内容准备：**
```markdown
AI搜索偏好：
- 清晰的问答格式（Q: ... A: ...）
- 数据和引用来源标注
- 专家观点引用（如"根据《中国居民膳食指南》..."）
- 步骤指南和清单

执行动作：
1. 每篇SEO文章添加FAQ区块（3-5个问题）
2. 添加"参考来源"区块（研究数据/指南链接）
3. 文章开头添加"本文要点"摘要（3-5条）
4. 使用H2/H3结构化标题（AI能识别层级）
```

**内容特征对齐：**
```markdown
AI搜索结果偏好内容特征：
✓ 专业但可读性强（不是学术论文）
✓ 有明确结论（不是"视情况而定"）
✓ 包含数据和来源
✓ 结构清晰（小标题+段落）
✓ 观点独特（不是泛泛而谈）

当前文章问题：
✗ 部分文章结论模糊（"视情况而定"过多）
✗ 缺乏最新数据引用
✗ 缺少专家背书
```
