# 荣旺健康营销自动化系统

基于 xiaohongshu-ops + agency-agents + marketingskills + autoresearch 最佳实践构建。

## 架构总览

```
product-marketing-context.md
├── 内容策略层（content-strategy）
│   ├── 选题发现（topic-discovery）
│   └── 内容日历（content-calendar）
├── 内容生产层（content-production）
│   ├── 内容生成（content-generate）→ 已有 API
│   ├── 爆款复刻（viral-copy）
│   └── 合规审查（compliance-review）
├── 发布执行层（publishing）
│   ├── 小红书发布（xiaohongshu）
│   ├── 公众号发布（wechat-oa）
│   ├── 抖音脚本（douyin）
│   └── 知乎内容（zhihu）
├── 数据复盘层（analytics）
│   ├── 账号分析（account-analysis）
│   └── 内容复盘（content-review）
└── 私域运营层（private-domain）
    ├── 私域导流（lead-capture）
    └── 用户运营（user-ops）
```

---

## 核心原则

1. **先读产品上下文** — 每次营销任务先读 `.agents/product-marketing-context.md`
2. **合规优先** — 保健品不得声称疗效，功效声称必须符合蓝帽子/OTC批件
3. **结构化输出** — 标题/正文/互动钩子/话题/风险标注五元组
4. **知识沉淀** — 每次分析结果落库 markdown，供后续复用
5. **先策略后创作** — 先确认选题方向和平台适配，再生成内容

## 触发场景与对应流程

### 场景A：内容批量生成（最常用）

**输入：** 产品名 + 功效关键词 + 目标人群 + 发布平台

**输出：** 跨平台适配内容草稿

```
步骤：
1. 读 product-marketing-context.md
2. 调用 /api/marketing/content-generate 生成内容
3. 适配目标平台格式（小红书/公众号/知乎/抖音）
4. 输出五元组：标题 + 正文 + 互动钩子 + 话题 + 风险标注
5. 确认合规后进入发布队列
```

### 场景B：爆款笔记复刻

**输入：** 竞品爆款笔记链接

**流程：**
1. 抓取原笔记结构（标题模板/封面/正文/互动机制/标签）
2. 提取可复用元素（结构、句式、情绪钩子）
3. 用 content-generate 生成"同主题第二篇爆款"
4. 保留核心互动机制，替换具体内容
5. 合规审查后输出

### 场景C：选题灵感

**输入：** 产品/品牌/行业关键词

**输出：** 5条可发布选题（带三段结构 + 互动钩子）

```
步骤：
1. 平台侧抓取信号（搜索小红书/知乎/抖音同题材高互动内容）
2. 需求侧补充（评论区观点分歧）
3. 结合账号定位生成选题清单
4. 每条包含：标题 + 角度 + 证据来源 + 风险提示
```

### 场景D：账号分析诊断

**输入：** 账号主页链接或名称

**输出：** 五维评分 + 诊断结论 + 优先动作

维度：定位清晰度/内容结构力/互动转化力/账号辨识度/增长可持续性

## 平台特性备忘

### 小红书
- 标题<=20字，封面信息层级清晰
- 70%有机生活内容/20%蹭热点/10%品牌硬广
- 发布时间：7-9PM、午餐时间
- 发布后2小时内互动关键

### 微信公众号
- 60%价值内容/30%社区互动/10%促销
- 打开率>30%为健康线
- 菜单架构要清晰
- 支持自动回复、关键词回复

### 抖音
- 完播率是核心指标
- 前3秒定生死
- 脚本结构：钩子(3秒)+痛点(5秒)+解决方案(15秒)+CTA(5秒)

### 知乎
- 专业背书为主
- 问答角度比文章角度更有流量
- 需要引用来源增加可信度

## 合规审查清单（每次必查）

- [ ] 不声称疗效（只说"有助于""辅助"）
- [ ] 功效词不超过蓝帽子/OTC批件范围
- [ ] 不夸大进口品牌背书
- [ ] 不贬低竞争对手
- [ ] 用户案例需注明"个体差异"
