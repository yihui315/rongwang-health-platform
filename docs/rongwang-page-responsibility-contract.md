## 二、AI 评估层职责（精确边界）

### 2.1 AI 评估入口页 (`/ai-consult`)

**唯一入口角色** — 不输出教育内容。

```
首屏：
  H1: "3 分钟了解你的健康风险分层"
  副标题: "基于你的症状、生活习惯和风险信号，生成个性化健康教育参考"
  主CTA: [开始 AI 评估]（唯一主CTA）
  次说明: "不替代医生诊断；中高风险建议优先就医"
```

**评估问卷步骤（最多 5 步）:**
1. 基本信息（年龄、性别）
2. 主要症状/困扰
3. 生活方式
4. 健康目标
5. 已有检查结果（可选）

### 2.2 AI 评估结果页

**必须包含:**
1. 风险分层: 低 / 中 / 高（颜色区分）
2. 解释卡: 3-5 条"为什么是这个方向"
3. 红旗信号: 哪些情况要优先就医（高亮提示）
4. 现在可以做什么: 生活方式建议
5. 推荐阅读: 对应健康方案（文字链接，不是弹窗）
6. 是否适合进入商品方向包（低/中风险显示，高风险不显示）
7. 保存报告 / 找顾问解读
8. AI 免责声明
9. 审核知识库版本号

**高风险结果（禁止出现）:**
- 商品推荐
- 购买按钮
- "适合你购买"
- 套餐 CTA

**低/中风险结果（按顺序）:**
1. 解释
2. 信任（顾问资质入口）
3. 方案
4. 商品方向包 / 顾问确认

## 三、健康方案层职责（精确边界）

### 3.1 评估入口页 (`/assessment/[type]`)

**角色**: 品类跳转入口，**不是迷你方案页**。

```
旧版（H1 + 4个卡片） → 删掉
新版：Hero 区域（H1 + 一句话 + 单一CTA）
  H1: [品类名] 健康评估
  副标题: "开始 AI 评估前，先了解这个方向是否适合你"
  主CTA: [开始 AI 评估] → /ai-consult?focus=[slug]
  次说明: 3-5 条适合人群（bullets，不是完整症状列表）
  底部: 免责声明
```

### 3.2 健康方案页 (`/solutions/[slug]`)

**角色**: 标准化循证内容 + 方向包预览，**不是第二个评估入口**。

**允许保留（Stage 1 后）:**
- 适合人群标签（targetAudience）
- 用户评分（rating）
- 生活方式建议（baselinePlan，简化版，不超过5条）
- 营养支持方向（supplementDirections，3-5条）
- 组合推荐（comboRecommendation，套餐卡片）
- 顾问支援（WeChatCTA，保持人类信任层）
- 成分说明表格（ingredients）
- 免责声明
- 底部信任栏（ProductTrustFooter）
- 作者/审核者/更新时间（Stage 3 加）

**必须删除（Stage 1 后）:**
- "1. 症状问题"（逐字重复 assessment 页）
- "2. 常见原因"（逐字重复 assessment 页）
- "3. 什么情况要就医"（医疗分诊逻辑，不是营养电商该做的）
- "4. AI自测入口"（重复 assessment 页的职责）
- "5. 基础调理方案"（与生活方式建议重复）
- "6. 营养支援方向" + "男女配方差异" + "OTC方向"（过度堆砌）
- "7. 完成评估后查看推荐"（教育内容，不是方案页职责）
- "荣旺方案 vs 普通方案"（竞品贬低，医疗合规风险）
- "真实案例分享"（未经核实的案例暗示疗效）
- "组合推荐"里的套餐购买按钮（Stage 2 才能出现）
- 顾问微信"添加顾问"按钮外的"在微信中打开"（过度导流）

**首屏结构（Stage 1 后）:**
```
Hero: [品类名] + 一句话价值主张
适合人群标签（3-5个）
评分
单一CTA: [先做 AI 评估]
---
适合人群详解（3-5条）
生活方式建议（简化版，5条以内）
营养支持方向（3-5条，bullet）
套餐预览（2-3个套餐卡片，可查看不可直接购买）
成分说明（表格，可折叠）
顾问支援（保持）
底部免责声明
```

## 四、CTA 管控规则

### 4.1 首屏 CTA 唯一性

| 页面 | 首屏 CTA 数量 | 允许的次级入口 |
|------|-------------|--------------|
| 首页 | 1个 | 信任入口（次级） |
| AI 评估页 | 1个 | 无 |
| 评估结果页 | 1个 | 保存报告（次级） |
| 评估入口页 | 1个 | 无 |
| 健康方案页 | 1个 | 套餐预览（次级） |
| 商品方向包页 | 1个 | 顾问确认（次级） |
| 信任中心 | 1个 | 无 |
| 文章页 | 1个 | 无 |

### 4.2 CTA 禁止混用

- 同一屏不得同时出现"开始 AI 评估"和"查看方案"
- 评估入口页不得出现"添加顾问微信"作为主 CTA
- 健康方案页不得出现"立即购买"
- 高风险结果页不得出现任何购买相关 CTA

## 五、禁止内容清单

### 5.1 医疗合规禁止

- 使用"治疗"、"治愈"、"根治"、"保证有效"、"彻底改善"
- 竞品对比中使用"普通方案效果有限"、"远超同类产品"
- 用户案例中暗示"服用XX天后好了"
- 高风险人群的购买引导
- AI 直接输出 SKU 推荐（必须通过规则层）

### 5.2 内容结构禁止

- 评估入口页出现4个以上内容块
- 健康方案页出现教育层（症状/原因/就医）放在AI入口之前
- 首屏出现2个以上同等权重的 CTA
- 在非评估结果页出现"适合你"的个性化表述

## 六、信任元素规范

### 6.1 必须包含

每个健康内容页必须包含：
- 作者姓名 + 角色
- 审核者姓名 + 角色
- 最近更新时间
- 参考资料（至少2条）
- 免责声明（正文底部）
- AI 内容标识（仅 AI 结果页）

### 6.2 证据等级标注

| 证据等级 | 标识 | 适用内容 |
|---------|------|---------|
| 强力证据 | 🟢 循证 | 通用医学共识、Natures等临床研究 |
| 中等证据 | 🟡 参考 | 专家共识、行业指南 |
| 初步证据 | 🔵 探索 | 初步研究、机制研究 |
| 传统使用 | ⚪ 传统 | 传统医学经验、个案报告 |
